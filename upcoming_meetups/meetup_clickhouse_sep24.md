# Your Data Stack Wasn't Built for AI Agents

**Date:** Thursday, September 24, 2025  
**Time:** 5:00 PM PDT  
**Location:** ClickHouse Seattle, 1000 Olive Way, Seattle, WA 98101  
**RSVP:** [meetup.com/pydata_seattle](https://www.meetup.com/pydata_seattle/events/316196700/)

---

As AI agents become real consumers of enterprise data — not just dashboards, analysts, or BI tools — the modern data stack needs to evolve.

Join **ClickHouse** and **PyData Seattle** for an after-work meetup exploring what it takes to build **agent-ready data systems**. We'll discuss how enterprise data infrastructure must adapt to support AI agents that need fast, contextual, governed, and reliable access to both structured and unstructured information.

**Topics include:**
- Agent-ready data pipelines
- Structured and unstructured data
- Semantic layers and retrieval
- Real-time context for AI systems
- Data quality and provenance
- Governance and permissions
- Natural-language analytics
- Enterprise data agents

**Format:** 3 × 25-minute talks + lightning demos + networking  
**Refreshments provided.**
